# Demo Script

Target length: about 90 seconds.

## 1. Boundary

Open Overview.

Say: Bland owns the phone conversation and Pathway flow. VoiceLab owns the business-action boundary behind it: typed normalization, identity, tenant policy, approval, idempotency, reconciliation, and audit.

## 2. Happy Path

Open Evals or the evidence doc first.

Say: the strongest external proof is a real Bland Console Webhook node calling VoiceLab with authenticated execution and Neon-backed persistence. This is not live telephony.

Then open Simulator and run the valid material request.

Open the trace. Show:

- caller identity resolved from phone number
- customer policy applied
- required fields present
- requisition created once
- `next_step.directive = continue`

## 3. Missing Information

Run or open a missing-quantity material request.

Show:

- quantity is required
- VoiceLab does not infer it
- no business mutation occurs
- `next_step.directive = clarify`

Bland would ask the caller for the missing quantity. VoiceLab only returns the required business state.

## 4. Approval

Run an over-threshold material request.

Show:

- policy threshold is deterministic
- approval request is created
- requisition is not created yet
- `next_step.directive = await_approval`

Open Approvals and approve the request. Show the action executes once and repeated approval replays the existing result.

## 5. Lost Response / Reconciliation

Open the recovery trace generated by screenshot automation.

Show:

- mock ERP write was attempted
- response was lost after the mutating request
- VoiceLab does not blindly retry
- action enters `reconciliation_required`
- operator reconciliation finds the existing mutation by idempotency/correlation key
- final state becomes recovered
- no duplicate requisition is created

## 6. Evidence

Open Evals.

Say: The evidence layers are a real Bland Webhook-node request, real Neon persistence, deterministic policy/action regression, and simulated ERP failure handling. Live phone-call quality and full Bland Agent Testing remain outside the claim.
